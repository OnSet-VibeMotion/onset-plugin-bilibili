# B 站上传助手

片场的独立发布插件。在项目的「发布」页选择 B 站账号，插件会在片场内嵌的 B 站创作中心上传成片、填写标题与简介、添加标签并设置封面。检查分区、稿件类型和裁切效果后，在 B 站页面手动投稿。

## 使用

1. 在片场设置中安装插件，打开项目的「发布」页。
2. 点「登录新账号」，在 B 站页面完成扫码或登录。多个账号的会话各自独立。
3. 准备 `publish.md` 中的成片路径、标题、简介和封面。插件优先采用 `copy.platform_titles.bilibili`、`copy.platform_hashtags.bilibili` 和 `cover.images` 中标为 `bilibili` 的 16:10 PNG 或 JPEG。专属标签为空列表时保持空白。
4. 选择账号，点「上传并填写」。插件会删掉 B 站自己预填的标签，封面在「封面制作」里勾上「双比例同步改动」，同一张图同时用在首页推荐（4:3）和个人空间（16:9）。必填的「创作声明」要你自己选，没选时插件会提醒。确认 B 站页面上的封面裁切、分区、创作声明和标签，再手动投稿。遇到验证码或身份确认时，在 B 站页面操作。
5. B 站页面单独开一个窗口，不挡片场：上传期间可以回片场照常工作。视频交给 B 站之后到填写完成，页面上会盖一层半透明遮罩显示进度，这期间不要操作页面，完成后自动解开。上传不设时限：窗口开着、页面没报上传失败，插件就一直等，传完自动接着填写，进度按上传百分比显示。不想等了可以在片场取消任务，B 站窗口会保留。
6. B 站弹出验证（滑块、短信或身份确认）时，插件揭开遮罩、把窗口拿到前面，停下全部自动操作，等你完成验证后自动接着做。
7. 上传前先查这个账号已开放和审核中的稿件：标题相同、时长对得上，就认为这个成片投过了，不上传，插件页面显示何时投的，确实要再投一次点「仍然上传」。读不到稿件列表时照常上传，并提醒你留意。
8. B 站上传页提示「本地浏览器存在 N 个未提交的视频」时，插件读 B 站存在本地的记录：只有一个、就是这个成片（文件名与大小一致），就点「继续编辑」接着填写，不重传；有别的视频就停下，请你先在 B 站窗口点「继续编辑」投稿或点「不用了」，插件不替你放弃，也不另传一份。
9. 「打开 B 站」会回到所选账号的窗口，可用来续登或检查当前投稿。B 站窗口还停在这个成片的编辑区时（例如上次等上传时中断了），再次点「上传并填写」会接着用，只重新填写文案与封面；成片换了或页面已离开编辑区，才回到上传页。

项目状态 `ready_to_publish` 表示可以开始人工检查，投稿结果以 B 站为准。

## 开发验证

`npm ci` 后可运行 `npm run check`、`npm run test:coverage` 和 `npm run test:browser`。用已构建的片场源码运行 `node scripts/check-host.mjs <片场源码目录>` 与 `node scripts/check-desktop.mjs <片场源码目录>`。修改源码后需重建随插件交付的 `dist/plugin.cjs`。

投稿界面依据 B 站创作中心的视频投稿页（`member.bilibili.com/york/videoup`，2026-11-19 按真实页面核对）。
